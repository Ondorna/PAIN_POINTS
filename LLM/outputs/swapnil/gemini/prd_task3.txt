Based on the ConnectHub Product Requirements Document (V3.2), here is the concise V1 product scope summary:

* **Approved V1 Features:**
  * Direct Messaging
  * Group Channels
  * User Profiles & Authentication
  * File Sharing
  * Notification System
  * Admin & Moderation Tools

* **Features Under Review:**
  * User Reputation System
  * Advanced Search

* **Is Video/Voice Calling planned for V1?:** No, video/voice calling capabilities are not in the current V1 priorities. 

* **Expected release phase for Video/Voice Calling:** Post-launch (previously discussed, but current priorities focus on bot frameworks, advanced search, and mobile app refinements).
